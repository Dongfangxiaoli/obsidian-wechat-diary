# 链接总结 V0.1 决策

## 决策

在现有插件内扩展，而不是另建微信 bot 或外部常驻服务。独立公开 URL 仍走原有日记写入；写入成功后才触发抓取与 AI 总结，摘要另存为 Markdown。

## 理由

- 扫码和真实微信收发已经可用，重复实现风险和维护成本都更高。
- Obsidian `requestUrl` 可直接抓取公开网页，现有 `AiClient` 已支持 OpenAI 兼容接口。
- “先保原文、后做增强”能保证抓取、AI 或网络故障不丢数据。

## 代价与边界

- 动态渲染、登录限制和反爬页面可能抓不到正文。
- 摘要依赖用户自己的 AI 接口与额度。
- V0.1 不做视频解析、OCR、队列服务和自动知识分类；出现真实高频需求再增加。

## 推翻条件

只有当大量目标链接必须登录、必须执行 JavaScript，或 Obsidian 关闭期间也必须后台处理时，才引入独立抓取服务。
